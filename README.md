Titanic Dataset - Exploratory Data Analysis (EDA)
This project contains a complete Exploratory Data Analysis (EDA) of the Titanic passenger dataset using Python, Pandas, and Seaborn.

🚀 Overview
The goal of this project is to explore passenger demographics, analyze missing values, compute summary statistics, and generate meaningful visualizations to understand the factors affecting passenger survival on the Titanic.

📊 Key Findings
Socioeconomic Privilege: 1st-class passengers had a significantly higher survival rate compared to 2nd and 3rd-class passengers.

Gender Disparity: Females experienced vastly higher survival rates across all classes due to rescue prioritization.

Age Vulnerability: Infants and young children were prioritized during rescue operations.

Ticket Cost Impact: Higher fare payments correlated with better cabin locations and improved chances of survival.

🛠️ Tools & Libraries Used
Python

Pandas & NumPy (Data manipulation)

Matplotlib & Seaborn (Visualizations)
